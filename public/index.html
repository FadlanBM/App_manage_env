Client Integration Workflow

Applications authenticate using dual-credential headers (X-App-Id and X-App-Secret). The vault verifies credentials against bcrypt hashes and decrypts the AES-256-GCM ciphertexts in memory before returning them over HTTPS/HTTP.

Send Credentials

Client calls GET /api/client/secrets passing X-App-Id and X-App-Secret.

Server Decrypts

Server verifies app secret, retrieves ciphertext from database, and decrypts using AES-256-GCM.

Runtime Injection

Client maps key-value response directly to local environment variables at boot.
